# ADR-007 — Recomendações com identidade verificável

**Status:** aceito para etapa 7. **Decisão:** candidatos com IDs e fonte real; excluir lidos/lendo de modo determinístico; ranking por perfil/avaliações/sentimentos/idioma/diversidade; IA opcional explica ou reordena candidatos já validados.

**Alternativas:** pedir títulos livres a LLM arrisca alucinação e duplicata; varrer Search API em massa não é uso adequado; só base pessoal não descobre obras novas.

**Consequências:** estudar dumps oficiais e qualidade de metadados antes de implantar; justificativa nunca inventa enredo nem ausência de temas.
