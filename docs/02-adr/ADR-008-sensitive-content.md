# ADR-008 — Classificação sensível com incerteza

**Status:** aceito para etapa 7. **Decisão:** explicit/detalhado bloqueado; contextual com aviso; desconhecido com ressalva; correção manual prevalece e conserva proveniência.

**Alternativas:** bloquear toda menção excluiria true crime contextual aceito; declarar seguro sem evidência é falso.

**Consequências:** filtro também na seção da estante, sem remover vínculo; teste de falsos positivos/negativos com revisão da proprietária.
