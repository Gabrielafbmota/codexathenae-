# Documentação do CodexAthenae

Esta pasta reúne a documentação funcional, arquitetural e operacional do projeto.

## Estrutura

- `product/`: visão, escopo e glossário do produto.
- `architecture/`: arquitetura, decisões técnicas, segurança e observabilidade.
- `specifications/`: especificações funcionais e técnicas por feature.
- `planning/`: roadmap, plano de implementação, riscos e backlog.
- `prompts/`: prompts incrementais para execução das tarefas com agentes de código.

## Princípios

- Clean Architecture e SOLID.
- API-first.
- 12-Factor App.
- Segurança baseada em OWASP.
- Regras de negócio independentes de frameworks e infraestrutura.
- Testes automatizados para toda funcionalidade nova.
- Mudanças pequenas, verificáveis e entregues por pull request.

## Fonte de verdade

- O repositório Git é a fonte oficial para código, especificações aprovadas, decisões arquiteturais e planejamento executável.
- Ferramentas externas de anotações podem apoiar pesquisa e ideação, mas não substituem os artefatos versionados aqui.
