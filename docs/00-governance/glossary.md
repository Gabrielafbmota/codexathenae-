# Glossário

- **Obra:** identidade bibliográfica do livro, independente de capa, formato e exemplar.
- **Edição:** publicação/formato específico; no cadastro pessoal indica posse, opcional no MVP 1.
- **Exemplar:** cópia física/digital de uma edição; quantidade idêntica ainda não definida.
- **Sessão de leitura:** leitura ou releitura de uma obra, possivelmente associada a edição.
- **Evento de progresso:** lançamento datado de página/percentual, nota curta e/ou sentimentos.
- **Evidência de leitura:** estado lido importado, declaração manual ou sessão concluída, sem data presumida.
- **Estante automática:** projeção derivada (`Quero ler`, `Lendo`, `Lidos`).
- **Estante pessoal:** coleção persistida (`Favoritos`, `Detestados`, personalizada).
- **Fonte bibliográfica:** Open Library ou Google Books; identidade e metadados com proveniência.
- **Candidato:** obra verificável ainda não salva, antes de confirmação/deduplicação.
- **Tema explícito/contextual/desconhecido:** classes para filtro sensível futuro; desconhecido não significa ausente.
